# inputs/

Your personal files. Everything here except this README is gitignored.

| Path | Created by | What it is |
|------|------------|------------|
| `source/` | you | Your existing resume (PDF, DOCX), plus any extras: older resumes, a brag doc, a LinkedIn export, project notes. More material gives a richer source resume. |
| `resume_full.html` | `/0-setup-resume` | Your "full" resume: every role, bullet, and metric you have. The tailoring steps pick from it and may not claim anything that isn't in it. **Review it carefully.** |
| `resume_full.css` | `/0-setup-resume` | Styling for the resume (copied from `templates/resume.css`). Edit it to change the look of every tailored resume. |
| `profile.md` | `/0-setup-resume` | Name, output filename prefix, contact, location, work authorization, cover-letter sign-off. |

You can edit `resume_full.html` and `profile.md` by hand at any time. Later runs pick up the changes.
